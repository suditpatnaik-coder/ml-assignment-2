# Dataset source and license

Dataset: Optical Recognition of Handwritten Digits, UCI Machine Learning Repository, Dataset ID 80.
DOI: https://doi.org/10.24432/C50P49
License on UCI page: Creative Commons Attribution 4.0 (CC BY 4.0).

This project uses scikit-learn's bundled 1,797-sample copy of the UCI test portion and renames the 64 features as pixel_0_0 through pixel_7_7.
